# Professional Course Materials: Mathematics for Computing & Engineering

[![Coursera Certificate](https://img.shields.io/badge/Coursera-Certificates-blue?logo=coursera)](https://www.coursera.org)

This repository contains a comprehensive, highly visual collection of study notes, lecture diagrams, and reference manuals for fundamental mathematical disciplines essential to computer science, data science, artificial intelligence, and engineering fields.

The content is organized into two primary course streams:

- **Geometry & Calculus for Computing**
- **Matrix Algebra for Engineers**

Each course directory includes a comprehensive textbook/guide in PDF format alongside a structured collection of high-resolution lecture diagrams for efficient visual learning and revision.

## 📘 Modules Breakdown

### 1. Geometry and Calculus for Computing

This module bridges classical geometric reasoning with foundational calculus specifically tailored for computing, algorithmic optimization, computer graphics, machine learning, and physics-based simulations.

#### Topics Covered

- Cartesian Coordinate Systems
- Angles and Triangles
- Trigonometric Functions
- Unit Circle
- Sine and Cosine Rules
- Linear Functions
- Quadratic Functions
- Exponential Functions
- Logarithmic Functions
- Function Transformations
- Limits and Continuity
- Introduction to Differentiation
- Differentials of Elementary Functions
- Polynomial Differentiation
- Product Rule
- Quotient Rule
- Chain Rule
- Optimization Techniques
- Partial Derivatives
- Gradient Vectors
- Kinematics
- Laws of Motion

#### Applications

- Computer Graphics
- Physics Engines
- Optimization Algorithms
- Data Science
- Machine Learning
- Scientific Computing

### 2. Matrix Algebra for Engineers

This module provides a rigorous introduction to linear algebra, emphasizing matrix computations, vector spaces, transformations, and decomposition methods used throughout engineering and modern AI systems.

#### Topics Covered

- Matrix Operations
- Matrix Multiplication
- Matrix Inversion
- Gaussian Elimination
- Elementary Matrices
- Permutation Matrices
- Rotation Matrices
- Transpose Operations
- Vector Spaces
- Linear Independence
- Span and Basis
- Dimension
- Column Space
- Row Space
- Null Space
- Left Null Space
- LU Decomposition
- Reduced Row Echelon Form (RREF)
- Determinants
- Laplace Expansion
- Leibniz Formula
- Eigenvalues
- Eigenvectors
- Matrix Powers
- Diagonalization
- Orthogonal Matrices
- Orthogonal Projections
- Gram-Schmidt Orthogonalization
- Least Squares Problems

#### Applications

- Machine Learning
- Deep Learning
- Computer Vision
- Robotics
- Signal Processing
- Engineering Simulations
- Data Transformations
