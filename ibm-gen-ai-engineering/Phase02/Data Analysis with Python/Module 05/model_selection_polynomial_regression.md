# Model Selection in Polynomial Regression

## Overview

Polynomial Regression is an extension of linear regression that models the relationship between the independent variable (`x`) and the dependent variable (`y`) using a polynomial equation.

One of the most important tasks is **selecting the correct polynomial degree (order)**. Choosing an order that is too low or too high results in poor model performance.

---

# Training Data

The training data is assumed to be generated by:

\[
y = f(x) + \text{noise}
\]

where:

- **f(x)** = true underlying function
- **Noise** = random error that cannot be predicted

The objective is to estimate **f(x)** as accurately as possible.

---

# Underfitting

## Definition

Underfitting occurs when the model is **too simple** to capture the relationship in the data.

Example:

- Linear Regression
- Low-degree polynomial (Degree 1 or Degree 2)

### Characteristics

- High training error
- High testing error
- Misses important patterns
- Poor prediction accuracy

### Example

```
Actual Curve

      *
    *   *
  *       *
 *         *

Linear Fit

-----------
```

The straight line cannot follow the curved pattern.

---

# Better Polynomial Degree

Increasing the polynomial degree makes the model more flexible.

Example:

- Degree = 8

Characteristics:

- Fits training data well
- Captures curve shape
- Estimates inflection points accurately
- Generalizes well

This is considered the **optimal model**.

---

# Overfitting

## Definition

Overfitting occurs when the model is **too complex** and starts learning the random noise instead of the actual relationship.

Example:

- Degree = 16

Characteristics:

- Very low training error
- High testing error
- Fits noise
- Poor predictions on unseen data
- Oscillates between data points

Example visualization:

```
Training Points

*   *    *   *

16th Degree Polynomial

~~~^^^^~~~^^^^~~~
```

The model follows every training point but loses the true trend.

---

# Model Complexity

```
Too Simple ---------------------- Too Complex

 Underfitting     Optimal      Overfitting
```

---

# Mean Squared Error (MSE)

Model performance is evaluated using:

- Training Error
- Testing Error

## Training Error

- Decreases continuously as polynomial degree increases.

```
Degree ↑

Training Error ↓
```

---

## Testing Error

Testing error behaves differently.

```
Error

 ^
 |\
 | \
 |  \
 |   \__
 |      \__
 |         \____
 +-------------------->

      Polynomial Degree
```

It:

- Decreases initially
- Reaches minimum
- Increases due to overfitting

The **best polynomial order** is the one with the **lowest testing error**.

Example:

```
Best Degree = 8
```

---

# Choosing the Best Polynomial

```
          Test Error

            ^
            |
 Underfit    |     Overfit
     \       |      /
      \      |     /
       \_____|____/
             ↑
      Best Polynomial
```

Rule:

- Left of optimum → Underfitting
- Right of optimum → Overfitting

---

# Irreducible Error

Even the best model cannot eliminate every error.

Reason:

The training data contains **random noise**.

```
y = f(x) + Noise
```

Since the noise is random, it cannot be predicted.

This unavoidable error is called:

> **Irreducible Error**

---

# Other Sources of Error

Errors can also occur because:

- Wrong model assumption
- Missing important features
- Insufficient training data
- Incorrect data distribution

---

# Wrong Model Example

Suppose data is generated by a sine wave.

```
True Function

~~~~~~~


Polynomial

/\___/\____
```

Polynomial regression cannot accurately represent periodic functions.

Therefore,

- Model assumption is incorrect.
- Prediction accuracy decreases.

# R² Score

Instead of visually inspecting every curve, we can evaluate models using the **Coefficient of Determination (R²)**.

## Formula

\[
R^2 = 1 - \frac{RSS}{TSS}
\]

Where:

- RSS = Residual Sum of Squares
- TSS = Total Sum of Squares

---

## Interpretation

| R² Value | Meaning                        |
| -------- | ------------------------------ |
| 1.0      | Perfect prediction             |
| 0.9      | Excellent fit                  |
| 0.7      | Good fit                       |
| 0        | Predicts only the mean         |
| Negative | Worse than predicting the mean |

Higher R² indicates a better model.

# Calculating R² for Multiple Polynomial Degrees

## Procedure

1. Create an empty list for storing R² scores.
2. Create a list of polynomial degrees.
3. Iterate through each degree.
4. Generate polynomial features.
5. Transform training data.
6. Train the regression model.
7. Transform testing data.
8. Predict test outputs.
9. Compute R² score.
10. Store the R² value.
11. Select the degree with the highest R².

---

## Pseudocode

```python
scores = []

degrees = [1,2,3,4,5]

for d in degrees:

    poly = PolynomialFeatures(degree=d)

    X_train_poly = poly.fit_transform(X_train)

    X_test_poly = poly.transform(X_test)

    model.fit(X_train_poly, y_train)

    r2 = model.score(X_test_poly, y_test)

    scores.append(r2)
```

# Key Concepts

- Polynomial Regression models nonlinear relationships.
- Model selection determines the optimal polynomial degree.
- Underfitting occurs when the model is too simple.
- Overfitting occurs when the model is too complex.
- Training error always decreases with model complexity.
- Testing error decreases initially, then increases.
- Choose the polynomial degree with the **lowest testing error**.
- Random noise introduces **irreducible error**.
- A wrong model assumption also increases prediction error.
- **R² Score** measures how well the model explains the data.
- In the horsepower example, **Degree 3** produced the highest R² and the best predictions.

# Interview Questions

### 1. What is model selection?

Selecting the machine learning model (or polynomial degree) that provides the best performance on unseen data.

---

### 2. What is underfitting?

A model that is too simple to capture the underlying relationship in the data.

---

### 3. What is overfitting?

A model that memorizes the training data and noise instead of learning the true pattern.

---

### 4. Why is testing error preferred over training error?

Testing error measures the model's ability to generalize to unseen data.

---

### 5. Why does training error always decrease with higher polynomial degree?

A more complex model has greater flexibility and can fit the training data more closely.

---

### 6. What is irreducible error?

The unavoidable prediction error caused by random noise in the data.

---

### 7. Why can't a polynomial fit every dataset well?

Because the true relationship may not be polynomial (e.g., sine waves or periodic functions).

---

### 8. What does an R² value close to 1 indicate?

The model explains most of the variability in the target variable and provides accurate predictions.

---

### 9. How do you choose the best polynomial degree?

Select the degree with the **lowest testing error** or **highest R² score** on unseen data.

---

### 10. In the horsepower example, which polynomial degree was optimal?

**Degree 3**, because it achieved the highest R² score without overfitting.
