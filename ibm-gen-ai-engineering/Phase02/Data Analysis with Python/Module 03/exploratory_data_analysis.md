# Exploratory Data Analysis (EDA)

## Introduction

Exploratory Data Analysis (EDA) is the process of analyzing a dataset to:

- Summarize its main characteristics.
- Better understand the dataset.
- Discover relationships between variables.
- Identify the most important variables for solving a problem.

## Objective of this Module

**Main Question:**

> Which characteristics have the greatest impact on the price of a car?

The module introduces several EDA techniques to answer this question.

## Topics Covered

### 1. Descriptive Statistics

Descriptive statistics provide a summary of a dataset.

**Purpose**

- Describe the basic features of the data.
- Produce a concise summary of the sample.
- Understand the distribution and measurements of the data.

### 2. Grouping Data (GroupBy)

Python's `GroupBy` operation is used to:

- Group similar data together.
- Perform calculations on grouped data.
- Transform the dataset into a more meaningful format.
- Compare categories efficiently.

### 3. ANOVA (Analysis of Variance)

ANOVA is a statistical technique that:

- Compares the means of different groups.
- Divides the variation in observations into distinct components.
- Determines whether differences between groups are statistically significant.

## Key Learning Outcomes

After this module, you should be able to:

- Understand the purpose of Exploratory Data Analysis (EDA).
- Use descriptive statistics to summarize datasets.
- Apply GroupBy to organize and analyze grouped data.
- Understand the basic idea behind ANOVA.
- Identify the variables that most influence car prices.
