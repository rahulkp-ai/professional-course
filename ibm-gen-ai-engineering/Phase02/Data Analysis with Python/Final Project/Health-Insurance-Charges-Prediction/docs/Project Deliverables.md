## Project Deliverables

The completed project will contain:

### 1. Dataset

- The cleaned and processed health insurance dataset.

### 2. Exploratory Data Analysis

- Visualizations and statistical analysis describing the dataset and relationships between features.

### 3. Regression Models

Implementation of:

- Simple Linear Regression
- Multiple Linear Regression
- Ridge Regression

### 4. Model Evaluation

Performance comparison using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Coefficient of Determination ($R^2$ Score)

### 5. Final Prediction System

- A trained regression model capable of receiving an individual's attributes and producing an estimated health insurance charge.
