## Project Scope

The scope of this project is limited to **predicting health insurance charges using structured tabular data**.

### In-Scope Activities

The project focuses on:

- Data preprocessing
- Exploratory data analysis
- Feature analysis
- Regression modeling
- Regularization
- Model evaluation
- Prediction

### Out-of-Scope Activities

The project does **not** attempt to:

- Diagnose medical conditions
- Recommend medical treatments
- Determine actual medical expenses
- Replace insurance underwriting professionals
- Provide clinical decision-making
- Establish causal relationships between health factors and insurance costs
